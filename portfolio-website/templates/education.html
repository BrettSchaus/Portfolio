Master's Degree in Mechatronic Engineering

Politecnico di Torino — Turin, Italy

Specialized in mechatronic engineering with a focus on automatic control, robotics, electronics, automation, and electric mobility technologies.

Below all courses completed:

Digital Control Technologies and Architectures

Description

Studied digital control systems and the design of discrete-time controllers for mechatronic applications, including modelling, simulation, and implementation using MATLAB and Simulink.

Modelling and Simulation of Mechatronic Systems

Description

Developed mathematical models and simulations of dynamic mechatronic systems, with applications to mechanical, electrical, and automotive systems.

Electronic Fundamentals and Applications

Description

Studied fundamental electronic systems, including circuit theory, analog and digital electronics, active semiconductor devices, and operational amplifiers, with a focus on signal conditioning and embedded system interfacing.

Electronic Systems for Mechatronics

Description

Studied electronic systems used in mechatronic applications, including analog and digital electronics, signal acquisition, processing, and embedded electronic architectures.

Estimation, Filtering and System Identification

Description

Studied techniques for identifying dynamic system models from experimental data, together with estimation and filtering methods for systems affected by noise and uncertainty.

Automatic Control

Description

The course will address the fundamentals of dynamical systems analysis and of the design of simple feedback controllers.

Robotics

Description

Studied robotic systems with emphasis on robot kinematics, dynamics, trajectory generation, and control of industrial and mobile robots.

Automation and planning of production systems

Description

Modern planning and production systems are based on a plethora of components that must cooperate to attain the desired business goals. In this context, MSc students in Mechatronics need to acquire the basic working principles of these components, as well as a proper technical language that will enable them to establish more effective and fruitful interactions within production sites.

Modern Design for Control Systems

Description

Study of modern robust control methods for designing feedback systems that remain stable and perform reliably despite plant uncertainties and disturbances. Covers robust stability, robust stabilization, and controller design for uncertain scalar and multivariable systems.

Software Architecture for Automation

Description

The course provides students with the theoretical knowledge and practical software engineering tools required to design and develop control software for modern industrial automation systems.

Electrical Technologies for eMobility

Description

Studied the main components of electric traction systems, including batteries, power electronic converters, and electrical machines, with emphasis on their integration into electric powertrains.

Automotive Control Systems

Description

Studied modelling and control of automotive systems, including vehicle dynamics, chassis systems, engines, and drivetrains. Applied control techniques through simulation and performance analysis.

Networking Technologies for Connected Vehicles

Description

Studied communication and networking technologies used in connected vehicles, including vehicle networks, vehicle-to-vehicle and vehicle-to-infrastructure communication, as well as vehicle localization systems.
